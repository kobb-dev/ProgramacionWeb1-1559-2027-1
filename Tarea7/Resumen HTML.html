Resumen HTML: principles conceptos y etiquetas

EstA pagina va resumir los principles conceptos y etiquetas vistas en la clase de programacion web 1, en el modulo HTML

Conceptos principales HTML

HTML

Es un lenguje de marcado de hipertexto es un lenguje de marcas qu se utiliza para estructurar sitios web

Elemento HTML

Un elemento HTML es la unidad basica de estructur y contenido de una pagina web, esta compuesta de:

  1. Etiqueta de apertura
  2. Pares Atributo-Valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <head>

Es una etiqueta que se utiliza para comunicarse con el navegdor atraves de los metadatos, permite mejorar el SEO, ademas se enlazan archivos externos de estilos o scripts

Etiqueta <body<>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra pagina web

Contenedores semnticos

<Header> Es un etiqueta utilizada para el contenido introductorio de una pagina web, puede contener el logo, el menu de navegcion principal, el nombre de la empresa, etc.
<nav> Etiqueta utilizada para el menu de navegacion principal, suele contener enlaces otras paginas relacionadas o navegr por la pagina principal, no debe de haber mas de una en la pagina
<Main> Etiqueta unica de una pagin web cuyo proposito es resltar nuestro objetivo o mensaje principal del sitio web, dentro se colocara el contenido principal de nuestra pagina
<section> Es una etiqueta que poco a poco se intenta ue sustituya a <div>, su uso es para definir a una pagin web en secciones y agrupar contendo relacionado
<article> Es una etiqueta que se utiliza para agrupar contenido autonomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encbezado
<footer> Es un etiquet que normalmente se encuentra al final de una pagina y funciona como cierre del sitio web, menudo contiene datos de contcto, derechos de autor u otra informacion complementari
<aside> Esta etiquet represent una seccion de la pagin web cuyo contenido no esta relacionado con el contenido principal de la pagina, como barras laterales, publicidad, enlaces a articulos relacionados, etc
